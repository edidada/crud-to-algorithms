## 1. 反向传播 + 梯度下降（AI / 机器学习）

### 1.1 它是什么

- **梯度下降（Gradient Descent）**：一台"蒙眼下山"的机器。误差是一个山峰连绵的曲面，每次沿最陡的下坡方向走一小步，逐步走到山谷（误差最小处）。
- **反向传播（Backpropagation）**：一种高效计算"每个参数对误差贡献了多少"的动态规划——从输出层倒着逐层推回输入层，避免重复计算。

神经网络训练 = 反向传播（算梯度）+ 梯度下降（用梯度更新参数）。大模型、推荐系统、CV/NLP 全部建立在这两个算法上。

### 1.2 前置知识（按学习顺序）

| # | 知识点 | 学到什么程度 | 业务代码类比 |
| --- | --- | --- | --- |
| 1 | 函数、导数、偏导数 | 会求 `f(x,y)` 对 x、y 各自的变化率 | "改这一个参数，指标动多少" |
| 2 | 链式法则 | `(f∘g)'(x) = f'(g(x))·g'(x)`，多层嵌套求导 | 埋点链路逐级拆分成导数 |
| 3 | 向量、矩阵乘法、转置 | 会手算 `Wx + b`，明白 `(AB)ᵀ = BᵀAᵀ` | 一层全连接就是 `matmul + bias` |
| 4 | 梯度 ∇f = (∂f/∂x, ∂f/∂y, …) | 指向函数上升最快的方向 | "调参最快见效的方向" |
| 5 | 泰勒展开（一阶近似） | 理解"沿 -∇f 走一小小步，误差确实下降" | 为什么学习率不能太大 |
| 6 | 凸函数与局部/全局最优（硕博） | 明白为什么可能收敛到"半山腰" | 局部缓存命中 ≠ 全局最优 |
| 7 | 概率与交叉熵（本科） | 会算两个概率分布的差异 | softmax + 交叉熵 = 分类损失 |
| 8 | 链式法则的矩阵形式（雅可比矩阵，硕博） | 能推出 `δˡ = (Wˡ⁺¹)ᵀ δˡ⁺¹ ⊙ σ'(zˡ)` | 反向传播就是"逐层复用下游的导数" |

### 1.3 最小示例：手推两层网络的一步反向传播

```python
# 正向：h = relu(W1 x + b1);  y = h W2 + b2;  loss = (y - t)^2
# 反向（自动求导做的事，等价于：
dL_dy    = 2 * (y - t)              # ∂loss/∂y
dL_dW2   = h.T @ dL_dy              # 链式法则 + 矩阵求导
dL_dh    = dL_dy @ W2.T
dL_drelu = dL_dh * (h > 0)          # relu 的导数是 0/1 门
dL_dW1   = x.T @ dL_drelu
W1 -= lr * dL_dW1                   # 梯度下降：往“下坡”走一步
W2 -= lr * dL_dW2
```

只要会矩阵乘法和链式法则，你就是能看懂 PyTorch `loss.backward()` 在做什么的人。

### 1.4 深入路线

- 入门：3Blue1Brown《神经网络》系列（把梯度可视化）。
- 进阶：Michael Nielsen *Neural Networks and Deep Learning* 免费在线书，手写一个不加框架的神经网络。
- 硕博级：《Deep Learning》（Goodfellow，花书）第 4 章数值计算、《凸优化》（Boyd）。
- 数学笔记：见 `third_party/math` 中微积分与线性代数部分。

## 2. 路径追踪 / 光线追踪（图形学）

### 2.1 它是什么

- **光线追踪（Ray Tracing）**：人不往屏幕"投射"眼睛视线，而是从相机往场景里发射一根根光线，找到该光线"看到"的物体，再继续追它反弹、折射后的光。电影特效、游戏画质、离线渲染的核心。
- **路径追踪（Path Tracing)**：光线追踪 + 蒙特卡洛随机采样 = **用概率方法数值求解"渲染方程"**（一个积分方程）。Pixar、NVIDIA 的画面本质上是解了几十亿个积分。

### 2.2 渲染方程（图形学的麦克斯韦方程组）

```
L(x → ω) = Le + ∫ f(x, ω, ω') · L(x' → x) · cos(θ) dω'
```

含义：某点朝某方向"发出"的亮度 = 自发光 + 对半球所有入射方向积分（反射光 × BRDF × 余弦项）。**这是个 you-can't-solve-it 的连续积分**，所以要用蒙特卡洛去"抽样求平均值"。

### 2.3 前置知识（按学习顺序）

| # | 知识点 | 学到什么程度 | 业务代码类比 |
| --- | --- | --- | --- |
| 1 | 线性代数：点/向量/叉积/点积/矩阵变换 | 会算距离、法线、旋转矩阵 | 三维坐标的"增删改查" |
| 2 | 立体解析几何 | 平面方程、球方程、光线求交 | 碰撞检测的数学版 |
| 3 | 定积分与多重积分 | 理解"对半球方向积分"就是求和的连续版 | 全表聚合 vs 抽样统计 |
| 4 | 概率基础：期望、方差、均匀分布 | E[X]=∫x·p(x)dx，大数定律 | "样本多了平均值就准" |
| 5 | 概率密度函数 PDF / 累积分布 CDF | 会用逆变换法从均匀随机数采样任意分布 | `rng.next()` 如何变成"按余弦分布" |
| 6 | 蒙特卡洛积分（本科高年级） | 无偏估计公式 (1/N)Σ f(Xi)/p(Xi) | 用 N 次随机抽样逼近某个聚合值 |
| 7 | 重要性采样 / 方差缩减（硕博） | 好的 PDF 让方差下降数倍 | hot key 走专门索引 |
| 8 | 测度论 / 辐射度学严格化（博士级） | 渲染方程的严格数学定义（Veach 论文） | 想读 Rolex 论文需要它 |

### 2.4 最小示例：用蒙特卡洛估 π（同一个算法家族的hello world）

```python
N = 1_000_000; hits = 0
for _ in range(N):
    x, y = random(), random()        # 在正方形里随机撒点
    if x*x + y*y <= 1: hits += 1     # 落进四分之一圆
print(4 * hits / N)                  # 期望 = π；误差 ~ 1/√N
```

路径追踪做的事一模一样，只是把"撒点"换成"光弹射"，把 π 换成"这片像素的亮度"。**重点掌握两点**：① 期望的写法 ② 误差随样本数按 1/√N 收敛（所以画面噪点永远存在，靠降噪算法救）。

### 2.5 深入路线

- 入门：Ray Tracing in One Weekend（免费三部曲），周末就能写出有噪点的渲染器。
- 进阶：*Physically Based Rendering: From Theory to Implementation*（PBRT，免费在线），工业级实现。
- 博士级：Eric Veach 的博士论文 *Robust Monte Carlo Methods for Light Transport Simulation*（重要性采样、多重要量采样 MIS 的源头）。
- 数学笔记：见 `third_party/math` 中概率论与积分部分。

## 3. 快速傅里叶变换 FFT（信号 / 图形 / 科学计算通用）

### 3.1 它是什么

把时域信号（一段波形）分解成"哪个频率的波强度多少"（频域谱）。直观例子：手机降噪、JPEG 压缩、语音识别的梅尔频谱、滤波器设计、大数乘法加速，全都依赖它。

- 朴素 DFT：O(n²)；FFT：O(n log n) —— 加速了十亿倍量级，被评为 20 世纪十大算法之一。

### 3.2 核心数学思想

把 n 个采样点对应的 n-1 次多项式 `A(x) = a0 + a1x + … + a{n-1}x^{n-1}` 在 **n 个特殊复数点（n 次单位根）** 上求值，利用单位根的对称性 `ω_n^{2k} = ω_{n/2}^k`，把问题递归一分为二。

### 3.3 前置知识（按学习顺序）

| # | 知识点 | 学到什么程度 | 业务代码类比 |
| --- | --- | --- | --- |
| 1 | 三角函数与和差化积 | cos(α+β) 展开会写 | 波形叠加的初等语言 |
| 2 | 复数与欧拉公式 e^{iθ} = cosθ + i sinθ | 把乘法理解为"旋转" | 复数=二维坐标的代数化 |
| 3 | 多项式：系数表示 vs 点值表示 | n 个点唯一确定 n-1 次多项式 | JSON 序列化 vs 索引快照 |
| 4 | n 次单位根 ω_n = e^{2πi/n} | 会推导 ω_n^{n/2} = -1（对折的钥匙） | 偶/奇分桶的数学依据 |
| 5 | 递推式与分治复杂度 T(n)=2T(n/2)+O(n) | 学会用主定理得 O(n log n) | 和归并排序是同一个复杂度 |
| 6 | 环论 / 代数结构（硕博级） | 在 Z_p 里找 n 次本原根做 NTT（数论变换） | FFT 的"整数精确版" |
| 7 | 信号与系统采样定理奈奎斯特（本科高年级） | 知道采样率的两倍才能还原信号 | 为什么 44.1kHz 是 CD 采样率 |

### 3.4 最小示例：FFT 的分治骨架

```python
def fft(a):                       # a: 系数列表，长度为 2 的幂
    if len(a) == 1: return a
    even = fft(a[0::2])            # 偶数下标子问题
    odd  = fft(a[1::2])            # 奇数下标子问题
    n, wn = len(a), cmath.exp(-2j * cmath.pi / len(a))
    y = [0] * n
    for k in range(n // 2):
        t = wn**k * odd[k]
        y[k]          = even[k] + t
        y[k + n//2]   = even[k] - t   # 关键：±t 只算一次，省一半
    return y
```

看懂这段代码所需的全部数学：复数乘法 + 单位根性质 + 二分递归。

### 3.5 深入路线

- 入门：看懂"蝴蝶操作"这张图，先会调用 numpy.fft。
- 进阶：算法导论第 30 章（多项式与 FFT，可配合 CLRS 原书）。
- 硕博级：CTFFT（Cooley–Tukey 的各种变体）、NTT 与多项式卷积在竞赛/密码学中的应用；信号处理方向读《Understanding Digital Signal Processing》。

## 4. 三个算法的"共同数学门槛"对照

| 维度 | 反向传播 | 路径追踪 | FFT |
| --- | --- | --- | --- |
| 核心数学 | 微积分 + 线性代数 | 概率 + 积分 | 复分析 + 代数 |
| 核心技巧 | 链式法则（动态规划思想） | 蒙特卡洛 + 重要性采样 | 分治 + 单位根对称性 |
| 复杂度红利 | 显式求导 O(n²) → 反向 O(n) | 穷举积分 → 期望估计 | O(n²) → O(n log n) |
| 直觉类比 | 倒着逐级查日志定位根因 | 用抽样统计代替全表扫描 | 换一种数据表示让乘法变查表 |
| 大致难度 | 大学二年级 | 大学高年级~研究生 | 大学高年级（硕博级才有趣） |

## 5. 建议的最小学习闭环（给 CRUD 程序员）

1. **Week 1–2**：补微积分与线性代数 → 手推两层网络的反向传播（不使用框架）。
2. **Week 3–4**：补概率 → 写出蒙特卡洛估 π，再读 Ray Tracing in One Weekend 第一部。
3. **Week 5**：补复数与单位根 → 手写出上面 20 行的递归 FFT。
4. 全程对照阅读 `third_party/math` 中的数学笔记，以及 CLRS 第 30 章对应 FFT、第 4 章对应分治。

> 记住：这三个算法的"数学难"不是符号游戏，而是**用更深的模型换来上千倍的性能或能力**——和你在业务里"加个索引换来 1000 倍查询速度"是同一种思维。
